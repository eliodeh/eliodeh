### 🎨 ASCII Art Engine: Command-Line Rendering Tool

> A full CLI tool that renders styled ASCII art from text, **built from scratch with no external art libraries.**

![Go](https://img.shields.io/badge/Go-00ADD8?style=flat-square&logo=go&logoColor=white)
![CLI](https://img.shields.io/badge/CLI%20Tool-203A43?style=flat-square&logo=gnubash&logoColor=white)
![Tested](https://img.shields.io/badge/Full%20Test%20Suite-00F5D4?style=flat-square&logoColor=0F2027)

**Key features**
- 🔤 Renders text into styled ASCII art using bitmap font banner files
- 💾 `--output=<file>` writes results to disk via `io.Writer`
- 🌈 `--color=<color>` applies ANSI highlighting with per-character position control
- 📐 `--align=<type>` aligns output in the terminal with ANSI-aware visible-width calculation
- ✅ A full test suite covering each function

**Engineering detail:** the banner lookup formula `(asciiValue - 32) * 9 + 1` encodes the entire character map. Getting row-by-row rendering and ANSI-stripped width calculations right took careful systems thinking.
